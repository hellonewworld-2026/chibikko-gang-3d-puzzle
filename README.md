# ちびっこギャング 3D大乱闘パズル (Chibikko Gang 3D Puzzle Blast)

ストリートの街並みを舞台にした、ちびっこギャングたちの痛快3Dマッチ3パズルゲーム！  
スマホ（iOS/Android）およびPCブラウザに完全対応。PWA対応によりホーム画面追加でネイティブアプリ感覚でフルスクリーンプレイできます。

---

## 🎮 ゲームの特徴

1. **爽快マッチ3＆3D立体パズル**:
   - 3つ以上揃えて消去。連鎖コンボでスコアとSPゲージが爆発的に上昇！
   - 4個消しでロケット花火、5個消しでレインボースプレー、特殊ピース合体技を搭載。

2. **ちびっこギャングのキャラクター＆必殺スキル**:
   - 🪙 レオ（スナイパー）、🔨 ゴリ（パワー）、🎨 エマ（策士）、⚡ ハヤト（スピード）。
   - SPゲージ満タンでカットイン演出とともに大迫力のスキルが発動！

3. **全12ステージの多彩なミッション＆ボスバトル**:
   - コイン収集、木箱破壊、南京錠解除、鍵落下、ボス討伐バトル。

4. **スマホ完全最適化＆ローカル即起動**:
   - `file://` プロトコル（ローカル直接起動）およびWeb（GitHub Pages）両対応。
   - 画面サイズに関わらず100%見切れずに収まるレスポンシブデザイン。

## 📱 スマホでの遊び方 (GitHub Pages への公開手順)

### ステップ 1: GitHub リポジトリへのアップロード
```bash
cd chibikko-gang-puzzle
git init
git add .
git commit -m "Initial commit: Chibikko Gang 3D Puzzle Blast"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/chibikko-gang-puzzle.git
git push -u origin main
```

### ステップ 2: GitHub Pages の有効化
1. リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** を `main`、フォルダを `/ (root)` に設定して **Save** をクリックします。
3. 発行された URL にアクセスします。

### ステップ 3: スマホでホーム画面追加
- **iPhone (Safari)**: 共有アイコン ➔「**ホーム画面に追加**」
- **Android (Chrome)**: メニュー ➔「**ホーム画面に追加**」または「**アプリをインストール**」
