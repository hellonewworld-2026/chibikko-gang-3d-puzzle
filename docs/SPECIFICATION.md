# 『ちびっこギャング 3D大乱闘パズル』詳細ゲーム仕様書

## 1. 基本概要
- **タイトル**: ちびっこギャング 3D大乱闘パズル (Chibikko Gang 3D Puzzle Blast)
- **ジャンル**: ストリートアクション・マッチ3パズルRPG
- **プラットフォーム**: Webブラウザ (iOS Safari / Android Chrome / PC Chrome, Edge, Firefox)
- **解像度設計**: 390×844px（9:19.5 スマホ最適化レスポンシブ、100dvh＆セーフエリア対応）

## 2. コアゲームメカニクス

### 2.1 ピース＆マッチ仕様
- **通常ピース (5種類)**:
  - 🪙 **ゴールドコイン**: イエロー（$マーク）
  - 🍬 **スカルルビージェム**: ピンク/マゼンタ（ダイヤモンド）
  - 🔫 **パチンコ・エメラルド**: グリーン（ターゲット）
  - 🎨 **スプレー缶**: シアン（パレット）
  - 💣 **ミニダイナマイト**: レッド（ライトニング）
- **特殊ピース生成**:
  - **4個直線消し**: ↔ / ↕ ロケット花火（直線一列一括破壊）
  - **L字・T字消し**: 💣 ダンボール爆弾（3×3範囲大爆破）
  - **5個直線消し**: 🌈 レインボースプレー（指定色の全消去）
  - **特殊ピース合体**: レインボー＋特殊、爆弾＋ロケットなどの合体超必殺技

### 2.2 ギミック＆お邪魔ブロック
- 📦 **ダンボール木箱**: 隣接マッチで破壊（耐久1〜2）
- 🔒 **南京錠チェーン**: マッチでロック解除
- 🔑 **黄金の鍵**: 最下段に落として金庫を開錠

### 2.3 キャラクター＆必殺スキル
- 🪙 **レオ（スナイパー）**: 『パチンコ・スナイプ』- ランダムな3マスを一撃爆破
- 🔨 **ゴリ（パワー）**: 『メガトン・ハンマー』- 下部2行を完全粉砕
- 🎨 **エマ（策士）**: 『カラー・ケミストリー』- 最多色のピースをすべて爆弾に変化
- ⚡ **ハヤト（スピード）**: 『タイム・トリック』- 残りターン+3＆盤面再シャッフル
